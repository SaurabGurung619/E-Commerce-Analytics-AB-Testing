# E-Commerce-Analytics-AB-Testing
A/B Testing – E-commerce Checkout Optimization

Developed an end-to-end A/B Testing project to evaluate whether a redesigned e-commerce checkout page improves purchase conversion and revenue compared with the existing page.

Tools & Technologies: Python, Pandas, SciPy, Statsmodels, SQL, MySQL, SQLAlchemy, PyMySQL, Power BI, Jupyter Notebook.

Skills Used:

Data Analysis: Data cleaning, data validation, exploratory data analysis (EDA), data aggregation, and KPI calculation.

SQL: CTEs, GROUP BY, aggregate functions, CASE statements, conditional logic, and business-focused queries.

Statistical Analysis: Hypothesis testing, two-proportion Z-test, p-value interpretation, 95% confidence intervals, and statistical significance.

Business Analytics: Conversion rate analysis, absolute and relative uplift, revenue per user, average order value, device performance, and traffic source analysis.

Data Visualization: Power BI dashboard development and presentation of actionable business insights.

Key Findings: Group B, representing the redesigned checkout page, achieved a 5.64% conversion rate compared with 5.03% for Group A. This represents a 0.61 percentage-point absolute uplift and a 12.05% relative improvement. The difference was statistically significant, with a p-value of 0.0194 at a 5% significance level. Revenue per user also increased by 13.49%.

Business Outcome: The analysis indicates that the redesigned checkout page performed better in terms of conversion and revenue per user. The project demonstrates how SQL, Python, statistical testing, and Power BI can be combined to support data-driven business decisions.
